# Feature: Reports

## 1. Purpose
Let users export fault data for a period and scope as XLSX, CSV or PDF, with a traceability header so every report can be audited.

## 2. Scope

### In scope
- Period and scope selection (reuses the selector from `analysis`)
- Export format cards: XLSX, CSV, PDF
- PDF report preview with traceability header
- "Report generated" confirmation dialog

### Out of scope
- On-screen charts and rankings (→ `analysis`)
